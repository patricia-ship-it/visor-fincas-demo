➕ Agregar Fincas Nuevas

Sube el Excel de superficies y el Shapefile de CROMOS para dar de alta una o varias fincas nuevas

1. Subir archivos

El Excel debe tener las columnas estándar (NIF, Província, Municipi, Agregat, Zona, Polígon, Parcel·la, Recinte, Producte, Sup. Decl, Tinença, Finca). El Shapefile debe ser el ZIP descargado de CROMOS ("Descarregar SHP"), con sus archivos .shp/.dbf/.prj adentro.

2. Confirmar antes de guardar

Revisa que cada fila del Excel tenga la geometría correcta emparejada. Si algo no se emparejó solo, elígelo manualmente en el desplegable.

Finca Cultivo Código SIGPAC Geometría

3. Separar líneas de fincas ya cargadas

Para recintos con varias declaraciones (por ejemplo GUARET 0,23 ha + TRITICALE 1,03 ha en el mismo recinto), el Shapefile de CROMOS trae un polígono por cada una. Sube el ZIP de un titular, o los de todos a la vez (puedes seleccionar varios), y cada línea ya cargada recibe su propio polígono, para verlas separadas en el mapa. Solo se tocan los recintos con más de una línea. No se cambia nada más.
